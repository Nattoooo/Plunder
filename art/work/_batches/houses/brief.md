# Batch `houses`

4 families. Draw every sprite listed below.

## Folder `buildings` rules

- Folder buildings, 21 sprites. Buildings show their front wall and roof, with the bottom of the wall on the bottom row. Doors are about 8 px tall so the captain fits through them. Draw roofs and plaster walls in the swap colours so towns can vary them.
- The game assembles town forts and the player's Coastal Fort (45 to 77 px wide) from these pieces, so the stone, battlements and outline must match across all of them and the tiling edges must line up exactly.
- The ten buildings a player can put on an island they own. The Coastal Fort is built from the fort pieces above, so it has no file of its own.

## Families

### `house-cottage` (new: draw from scratch)

- `house-cottage` 40 x 45 (flexible size): Single-storey cottage: plaster walls, tiled hip roof, centred door, two windows, chimney

### `house-shutters` (new: draw from scratch)

- `house-shutters` 40 x 41 (flexible size): Single-storey cottage with blue window shutters, no chimney

### `house-long` (new: draw from scratch)

- `house-long` 60 x 45 (flexible size): Long single-storey house: four windows, centred door, chimney

### `house-townhouse` (new: draw from scratch)

- `house-townhouse` 40 x 62 (flexible size): Two-storey townhouse: three windows upstairs, door and two windows below, chimney
