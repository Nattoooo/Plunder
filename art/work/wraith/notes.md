# wraith

Size change: 7 x 8 instead of 6 x 8 (flexible). The extra column lets the two eyes sit symmetrically in a 3 px hood opening.

## wraith-1
- Rows 0-1: hood top, outlined; one `I` highlight top-left (light from top left).
- Rows 2-4: dark `K` hood opening (face void); eyes are two `I` pixels, the only bright points, so they glow.
- Rows 5-6: tattered robe in teal `i`, no legs, flat body shape for a clear ghost silhouette.
- Row 7: ragged hem, three outline stubs with gaps, so it reads as floating and torn.

## wraith-2
Identical except the hem row is shifted by one pixel the other way (rippled opposite).
