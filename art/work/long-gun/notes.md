## long-gun (5 x 8, fixed)

- **Muzzle, row 0:** the outline closes the top of the barrel.
- **Barrel, rows 1-4 (`k N k`):** a 1 px iron core for four rows, so the length reads as slim.
- **Breech, row 5 (`N n M`):** the barrel widens to 3 px where the breech is, the thick end of a real long gun. It is the only iron wider than the barrel.
- **Wooden block, row 6 (`v v v`):** the carriage base, in the wood ramp. Only a short block shows, so the gun reads as a long barrel rather than a carriage.
- **Stern, row 7:** the outline closes the base.
