# fish (icons, 8 x 8, fixed)

Silver-blue fish facing left, forked tail on the right.

- Back `L` (lit) / `l` / `B` blue; belly `N` / `n` silver, so the fish reads as silver-blue from above.
- Fork tail: tips at the top and bottom right, notch on the right edge, so it does not read as a blob.
- One `k` eye on the head, the only detail point on the fish.
